# Implementation Plan: #21 文件导入词书（xlsx/txt/pdf + 词典查词 + POS 下拉）

## 决策已确认（与用户）

| 决策 | 选择 | 理由 |
|---|---|---|
| xlsx 解析 | **手写 OOXML 解析器**（ZipInputStream + XmlPullParser，~150 LOC，零依赖） | Fastexcel 本质是 POI 5.4.1 封装，Android 上 `javax.xml.stream` 缺失，APK +10MB。AGENTS.md §2 Simplicity First |
| PDF 解析 | **PdfBox-Android 2.0.27.0** + 简易表格解析（按行提取 + 列切分 + 字号过滤水印） | Tabula-java 依赖 PDFBox 2.0.24（用 java.awt，Android 不存在），项目自 2021 无更新 |
| 入口位置 | **LibraryScreen 「+ 新建词书」下方加「从文件导入」按钮** | 建词书入口同处，符合用户心智 |
| 手动加词条 POS 下拉 | **12 个固定项**（n./v./vt./vi./adj./adv./prep./conj./pron./art./num./int.） | 按 issue #9 字面；导入列4 解析表全集 ~17 个不变 |
| txt/csv | **内置解析**（Kotlin `lineSequence()` + `split`），无新依赖 | OpenCSV 5.10 能跑但词书 CSV 太简单，不值得依赖 |

## 关键设计点

### 1. PosMeaningParser（纯函数，JVM 单测主战场）

固定缩写表（issue 字面）：
```
n. v. vt. vi. aux.v. adj. a. adv. ad. prep. conj. pron. art. num. int. interj. abbr.
```
正则按"缩写+点+释义"模式切段，多段空格分隔。例：
- `"a.平坦的；平淡的 n.公寓；平面"` → `[("a.", "平坦的；平淡的"), ("n.", "公寓；平面")]`
- `"n.苹果"` → `[("n.", "苹果")]`
- 单段无缩写 → 视为 `"n."` 默认（issue 没说，取保守默认，避免整词丢释义）

### 2. XlsxParser（手写 OOXML，零依赖）

`.xlsx` = ZIP + OOXML。流程：
1. `ZipInputStream` 解开，找 `xl/sharedStrings.xml`（共享字符串表）+ `xl/worksheets/sheet1.xml`
2. `XmlPullParser` 解 sharedStrings → `List<String>`（按 <si> 顺序）
3. `XmlPullParser` 解 sheet1，每个 `<row>` → `List<String>`（cell 的 `t="s"` 引用 sharedStrings，否则 inline）
4. 每行按列索引取：col[0]=序号忽略，col[1]=单词，col[2]=音标？，col[3]=posMeaning？
5. 限制只读第一个 sheet

### 3. PdfTableParser（PdfBox-Android）

`PDDocument.load(InputStream)` → 遍历每页：
1. 用 `PDFTextStripper` 提取文本（已按行 sort by y）
2. 每行按 2+ 空格 / 制表符切成列
3. **水印过滤**：单行字符数 > 200 或单字符平均宽度异常大的行视为水印跳过（启发式，简单有效）
4. 列对齐：取前 4 列（同 xlsx 列结构）

### 4. FileWordImporter（@Singleton，编排器）

```kotlin
@Singleton
class FileWordImporter @Inject constructor(
    @ApplicationContext private val context: Context,
    private val db: WordDrillDatabase,
    private val wordDao: WordDao,
    private val bookDao: BookDao,
    private val dictionaryDao: DictionaryDao,
) {
    suspend fun import(uri: Uri, bookName: String): ImportSummary = withContext(Dispatchers.IO) {
        val format = ImportFormat.byExtension(uri Extensions)
        val rows = context.contentResolver.openInputStream(uri)!!.use { stream ->
            when (format) {
                XLSX -> XlsxParser.parse(stream)
                TXT -> TextTableParser.parse(stream, delimiter = null) // 自动 tab/多空格
                CSV -> TextTableParser.parse(stream, delimiter = ',')
                PDF -> PdfTableParser.parse(stream)
            }
        }
        db.withTransaction {
            val bookId = bookDao.insert(Book(name = bookName.trim(), isPreset = false))
            var success = 0; var skipped = 0
            for (row in rows) {
                if (row.word.isBlank()) { skipped++; continue }
                // 1) 先查 dictionary
                val dictEntries = dictionaryDao.findByWord(row.word.lowercase())
                if (dictEntries.isNotEmpty()) {
                    // 用词典数据：word + 各 sense + 词典 phonetic
                    val wordId = upsertWord(row.word, dictEntries.first().phonetic)
                    dictEntries.forEach { wordDao.insertSense(Sense(wordId, it.pos, it.meaning)) }
                    bookDao.linkBookWord(BookWord(bookId, wordId))
                    success++
                } else if (!row.phonetic.isNullOrBlank() || !row.posMeaning.isNullOrBlank()) {
                    // 2) 词典没有 → 用文件列3+4
                    val phonetic = row.phonetic?.takeIf { it.isNotBlank() }
                    val senses = PosMeaningParser.parse(row.posMeaning ?: "")
                    if (senses.isEmpty()) { skipped++; continue }
                    val wordId = upsertWord(row.word, phonetic)
                    senses.forEach { wordDao.insertSense(Sense(wordId, it.first, it.second)) }
                    bookDao.linkBookWord(BookWord(bookId, wordId))
                    success++
                } else {
                    // 3) 全空 → 跳过，计入数据不完整
                    skipped++
                }
            }
            ImportSummary(success, skipped)
        }
    }

    private suspend fun upsertWord(text: String, phonetic: String?): Long =
        wordDao.findIdByText(text) ?: wordDao.insert(Word(text = text, phonetic = phonetic)).let { id ->
            if (id == -1L) wordDao.findIdByText(text)!! else id
        }
}
```

**去重静默**：`word.text` 唯一索引（IGNORE 兜底）+ `(wordId, pos)` 唯一索引 + `(bookId, wordId)` 复合主键。重复词在不同文件导入或跨词书自动复用同一 word 行。无需显式去重逻辑。

## 风险与回退

- **PdfBox-Android 内存**：大 PDF 可能 OOM。加保护：PDDocument.load 用 File 而非 byte[]（PdfBox 已自己管理临时文件），限制单页行数 1000 上限。
- **xlsx 复杂格式**：合并单元格、公式、多 sheet 不支持（issue 没要求，文档里加 @throws 注释）。
- **POS 自动填充 debounce**：WordListViewModel 加简单的 `Job?` cancel 上次查询，300ms 后再查，避免每个字符都查库。
- **POS 解析无缩写默认 n.**：保守选择，issue 没明说。如果用户反馈不对再调。
